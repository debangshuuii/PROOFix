# PROOFix for VS Code & Cursor

### *Don't just write code. Prove that it works — directly in your IDE.*

The official **PROOFix Native IDE Extension** for Visual Studio Code and Cursor brings evidence-grounded application verification into your editor gutter:

- **Route Gutter Badges:** Directly beside Next.js route handlers (`app/**/page.tsx` and `app/api/**/route.ts`), displaying live pass/fail status lenses.
- **Inline CodeLens:** One-click `▶ Run Journey` and `🛡️ Prove Route` directly above exported components.
- **VS Code Test Explorer:** Seamless integration into the native Test Activity Bar with live step progress.
- **Inline Patch Application:** Click "Apply Proven Fix" to inspect side-by-side split diffs and apply fixes atomically.
